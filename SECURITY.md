# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report them privately through [GitHub's private vulnerability reporting](https://github.com/contalert/duedates/security/advisories/new)
or by email to **contato@contalert.com.br**. We aim to acknowledge reports within 3 business days.

## Supported versions

Security fixes are released for the latest minor version.
